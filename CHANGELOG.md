# Changes

## 1.0.0

First release.

- Tickets as JSON Lines; articles as a folder of Markdown, text or HTML files, or as JSON Lines.
- TF-IDF similarity between every ticket and every article; coverage, grouped gaps, most used and unused articles, near-duplicate articles.
- Masked ticket text in every report; `--min-coverage` as a gate.
- Reports as text, Markdown and JSON.
- Release packages come with a CycloneDX SBOM, SHA-256 checksums and a build provenance attestation.
